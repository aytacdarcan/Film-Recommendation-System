# Film Recommendation System

A simple movie recommendation web application built with Python and Flask.

The system allows users to search for a movie and get similar movie recommendations based on movie metadata. It also uses the TMDB API to fetch movie posters and additional movie information.

## Features

- Movie search
- Similar movie recommendations
- Flask backend
- HTML, CSS and JavaScript frontend
- TMDB API integration
- Movie metadata processing

## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS
- JavaScript
- TMDB API

## Dataset

This project uses TMDB movie metadata datasets.

Required CSV files:

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

These files are not included in the repository.  
You can download them from Kaggle TMDB Movie Metadata Dataset.
